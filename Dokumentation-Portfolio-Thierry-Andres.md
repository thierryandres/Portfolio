# Portfolio Thierry Andres

## Kurzbeschreibung
Diese Website ist mein persönliches Portfolio. Sie zeigt, wer ich bin, was ich aktuell in der Ausbildung mache und welche Grundlagen ich mir bereits erarbeitet habe.

## Ziel
Die Seite soll einen ehrlichen und unkomplizierten Einblick geben:
- zu meiner Ausbildung
- zu meinen Fähigkeiten
- zu meinen Hobbys
- und zu den wichtigsten Kontaktmöglichkeiten

## Seitenübersicht
- `index.html`: Startseite mit kurzer Vorstellung
- `ueber_mich.html`: Persönlicher Überblick
- `skills.html`: Technische Fähigkeiten, Soft Skills und Sprachkenntnisse
- `diplome.html`: Ausbildung und Zertifikate
- `hobbys.html`: Freizeit und Interessen
- `gallery.html`: Bildergalerie
- `contact.html`: Kontaktformular
- `impressum.html`: Rechtliche Angaben

## Technologiestand
- C# (Grundlagen)
- Java (Grundlagen)
- Python (Grundlagen)
- SQL (Grundlagen)
- Git (Grundlagen)
- Linux (Grundlagen)
- HTML/CSS/JavaScript (Grundlagen)

## Technische Umsetzung
Die Website bleibt bewusst leichtgewichtig:
- statische HTML-Seiten
- zentrales CSS unter `assets/css/styles.css`
- JavaScript unter `assets/js/main.js` für Navigation, Formular und Galerie-Slider
